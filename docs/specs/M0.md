# M0: Foundations

**Goal:** everything needed to start building exists and works: repo, CI, tools, the phone talking to the laptop, and a "hello camera" app running on the phone.

## Done when

- [x] Monorepo with `verifier/` at the top level; spike code moved in with history.
- [x] CI runs the verifier tests on every push and PR.
- [x] Repo on GitHub ([Hkayy47/margin](https://github.com/Hkayy47/margin)), CI green.
- [ ] `adb devices` lists your phone (Android Studio + USB debugging).
- [x] "Hello camera" app written (`app/`), typechecks, Android project generates.
- [ ] ...and runs on the phone: live camera preview, one button that takes a still.
- [ ] GPU works (`nvidia-smi` shows the RTX 5070), or we decide on Modal instead.
- [ ] API keys in a local `.env` (never committed): Gemini (billing on), Hugging Face.
- [ ] Phone stand bought or built; plain paper and a dark pen.
